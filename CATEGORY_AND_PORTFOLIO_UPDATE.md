# Обновление: Управление категориями и быстрое добавление проектов

## ✅ Что добавлено

### 1. Управление категориями в Pricing (НОВОЕ)

#### Функционал:
- **Переименование категорий** - изменение названия категории для всех услуг
- **Объединение категорий** - перемещение всех услуг из одной категории в другую
- **Удаление пустых категорий** - удаление категорий без услуг

#### Файлы:
- ✅ `app/admin/pricing/_components/CategoryManager.tsx` - компонент управления
- ✅ Обновлен `app/admin/pricing/actions.ts` - добавлены server actions:
  - `renameCategory(oldName, newName)`
  - `mergeCategories(fromCategory, toCategory)`
  - `deleteCategory(categoryName)`
- ✅ Обновлен `app/admin/pricing/_components/PricingBuilder.tsx` - добавлена кнопка "Категории"

#### Как использовать:
1. Перейдите в `/admin/pricing`
2. Нажмите кнопку **"Категории"**
3. Выберите действие:
   - **Переименовать** - кликните на карандаш рядом с категорией
   - **Объединить** - выберите две категории и нажмите "Объединить"
   - **Удалить** - кликните на корзину (только для пустых категорий)

#### Пример использования:
```
Было:
  - Терапия (5 услуг)
  - Лечение зубов (3 услуги)
  
Действие: Объединить "Лечение зубов" → "Терапия"

Стало:
  - Терапия (8 услуг)
```

### 2. Быстрое добавление проектов Portfolio (НОВОЕ)

#### Функционал:
- **Quick Add диалог** - быстрое создание проекта с основной информацией
- Минимальная форма (только обязательные поля)

#### Файлы:
- ✅ `app/admin/portfolio/_components/QuickAddPortfolio.tsx` - диалог быстрого добавления
- ✅ Обновлен `app/admin/portfolio/_components/PortfolioGridBuilder.tsx` - добавлена кнопка "Быстрое добавление"

#### Поля Quick Add:
- **Название проекта** * (обязательное)
- Подзаголовок
- Описание
- Категория
- URL обложки

#### Как использовать:
1. Перейдите в `/admin/portfolio`
2. Нажмите кнопку **"Быстрое добавление"**
3. Заполните минимальную форму
4. Нажмите "Создать проект"
5. Проект появится в сетке
6. Кликните "Редактировать" для добавления деталей

## 🎯 Преимущества

### Управление категориями:
1. **Без SQL** - все через UI, не нужны запросы к базе
2. **Безопасность** - нельзя удалить категорию с услугами
3. **Bulk операции** - переименование/объединение влияет на все услуги сразу
4. **Консистентность** - автоматическое обновление всех связанных записей

### Быстрое добавление проектов:
1. **Скорость** - создание проекта за 30 секунд
2. **Простота** - минимальная форма без отвлечения
3. **Гибкость** - можно добавить детали позже
4. **UX** - не нужно покидать список проектов
