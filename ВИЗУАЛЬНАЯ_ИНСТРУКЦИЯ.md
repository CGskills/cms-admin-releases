## 4. Пример заполнения ✨

### Проблема:
```
Разрушение жевательного зуба более чем на 60%. 
Пациент жаловался на дискомфорт при пережёвывании 
и эстетический дефект.
```

### Решение:
```
После санации полости рта и подготовки зуба была 
установлена металлокерамическая коронка, полностью 
восстановившая жевательную функцию и эстетику.
```

### Результат:
```
Полное восстановление формы и функции зуба. 
Пациент вернулся к привычному рациону без дискомфорта.
```

## 8. Before/After slider 🔄

### С изображениями До/После:

```
┌──────────────────────────┐
│      ┌────────┐          │
│ ДО   │  ПОСЛЕ │          │
│      └────────┘          │
│                          │
│      ◄────○────►         │
│       slider             │
└──────────────────────────┘
```

**Как это работает:**
1. Загружаете "Фото До"
2. Загружаете "Фото После"
3. На сайте автоматически появляется интерактивный слайдер
4. Посетитель может двигать ползунок чтобы сравнить

## 9. Тайм-лайн создания проекта ⏱️

```
1. Открыть форму
   ↓
2. Заполнить название
   ↓
3. Заполнить Problem/Solution/Result
   ↓
4. Загрузить изображение
   ↓
5. Настроить размер плитки
   │
   ├─ Выбрать пресет (4×280, 6×280...)
   │
   └─ Или ввести вручную (7×320)
   ↓
6. Нажать "Создать проект"
   ↓
7. ✅ Проект создан!
   ↓
8. Автоматически отображается в grid
```
