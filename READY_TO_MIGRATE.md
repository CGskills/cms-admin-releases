## 📋 ЧТО ВАМ НУЖНО СДЕЛАТЬ

### Шаг 1: Создать RELEASE_TOKEN (5 минут)

Следуйте инструкциям в **GITHUB_MANUAL_STEPS.md**:

1. Открыть: https://github.com/settings/tokens?type=beta
2. Generate new token
3. Token name: `CMS_ADMIN_RELEASE_TOKEN`
4. Repository access: **Only select repositories** → `cms-admin-releases`
5. Permissions: **Contents: Read and write**
6. Generate token
7. **СКОПИРОВАТЬ ТОКЕН**

### Шаг 2: Добавить в Secrets (2 минуты)

1. Открыть: https://github.com/CGskills/cms-admin/settings/secrets/actions
2. New repository secret
3. Name: `RELEASE_TOKEN`
4. Value: <вставить токен>
5. Add secret

### Шаг 3: Сообщить мне (1 секунда)

Написать: **"Токен создан и добавлен в Secrets"**

## ❓ ЧАСТЫЕ ВОПРОСЫ

### Q: Это безопасно?

A: **ДА**. Токен хранится зашифрованным в GitHub Secrets, имеет минимальные права, ограничен одним репозиторием, и может быть отозван в любой момент.

### Q: Код станет публичным?

A: **НЕТ**. Исходный код остается в приватном cms-admin. В публичный cms-admin-releases загружается только скомпилированный .exe.

### Q: Сломается ли что-то?

A: **НЕТ**. Изменения только в конфигурации публикации. Вся функциональность остается без изменений.

### Q: Можно ли откатить?

A: **ДА**. В MIGRATION_PLAN.md есть раздел "Откат" с пошаговыми инструкциями.

### Q: Что если я ошибусь при создании токена?

A: Можно пересоздать токен. Инструкции по решению проблем в GITHUB_MANUAL_STEPS.md.

### Q: Нужно ли переустанавливать приложение пользователям?

A: **НЕТ**. После первого релиза v0.2.5 все пользователи получат автоматическое обновление.
