## Проверка ошибок ❌

### Если появляются ошибки:

#### 1. **duplicate key value violates unique constraint**
- ❌ SQL миграция не выполнена
- ✅ Выполнить: `ALTER TABLE portfolio_items DROP CONSTRAINT portfolio_items_slug_key;`

#### 2. **column "problem" does not exist**
- ❌ Поля не добавлены в БД
- ✅ Выполнить: `ALTER TABLE portfolio_items ADD COLUMN problem TEXT DEFAULT '';`

#### 3. **Cannot read properties of undefined**
- ❌ TypeScript types не обновлены
- ✅ Перезапустить dev server

#### 4. **Images not uploading**
- ❌ Storage bucket не существует или нет прав
- ✅ Проверить bucket `portfolio` в Supabase Storage
- ✅ Проверить RLS policies

#### 5. **Form not submitting**
- ❌ JavaScript ошибка в браузере
- ✅ Открыть DevTools → Console
- ✅ Проверить ошибки и сообщить разработчику
