## 🐛 Исправления Code Library

### Превью HTML-фрагментов
**Проблема:** Фрагменты HTML с встроенными `<style>` и `<script>` тегами показывали вечную загрузку в превью.

**Причина:** 
- Функция `isCompleteBlock()` ошибочно считала такие фрагменты "полными документами"
- Фрагменты рендерились без `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>` — браузер не выполнял скрипты
- Sandbox iframe имел ограничение `allow-scripts` без `allow-same-origin`, что блокировало localStorage, sessionStorage и другие API

**Исправлено:**
1. ✅ Переработана логика `isCompleteBlock()` — теперь полными считаются **только** документы с `<!DOCTYPE html>` или `<html>`
2. ✅ Добавлена функция `extractEmbeddedCode()` для извлечения встроенных `<style>` и `<script>` из фрагментов
3. ✅ Превью автоматически извлекает встроенные стили/скрипты и оборачивает фрагмент в полный HTML-документ
4. ✅ Sandbox iframe получил `allow-same-origin` — разблокированы storage API и CORS-запросы
5. ✅ Экспорт корректно объединяет встроенный и отдельный CSS/JavaScript

### Импорт полных HTML-файлов
**Статус:** ✅ Работает корректно

Импорт через `seed-code-blocks` API сохраняет полные HTML-документы целиком в поле `html`, поля `css` и `javascript` остаются пустыми. При превью и экспорте такие документы обрабатываются без изменений.

## 📦 Изменённые файлы

### Ключевые компоненты
- `lib/code-blocks/export.ts` — переработана логика определения типа блока и экспорта
  - `isCompleteBlock()` — теперь только для полных документов
  - `extractEmbeddedCode()` — новая функция извлечения встроенных стилей/скриптов
  - `buildExportCode()` — умное слияние встроенного и отдельного кода

- `app/admin/code-library/_components/CodePreview.tsx` — исправлен рендеринг превью
  - Автоматическое извлечение встроенных стилей/скриптов из фрагментов
  - Правильная обёртка фрагментов в полный HTML-документ
  - Sandbox iframe с `allow-same-origin` для полной поддержки Web API

## 📋 Рекомендации

1. **Для пользователей:** Превью теперь корректно отображает все импортированные блоки. Если ранее импортированные блоки показывали пустое превью, попробуйте их переоткрыть.

2. **Для разработчиков:** При добавлении новых функций импорта учитывайте разницу между:
   - Полными HTML-документами (`isFullDocument()` → сохранять целиком)
   - Фрагментами с встроенными стилями (`extractEmbeddedCode()` → извлекать в отдельные поля)
   - Простыми фрагментами (оборачивать в namespace div)
