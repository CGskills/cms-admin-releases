## 🔍 Технические детали

### Почему это произошло?

1. Пользователь вошел в приложение
2. Создалась сессия без admin прав
3. Мы добавили пользователя в admin_users
4. Но JWT токен не обновляется автоматически
5. Функция `is_admin()` проверяет базу при каждом запросе
6. Но сессия остается старой

### Как работает is_admin()?

```sql
CREATE OR REPLACE FUNCTION public.is_admin()
RETURNS boolean AS $$
  SELECT
    COALESCE((auth.jwt() -> 'app_metadata' ->> 'role') = 'admin', false)
    OR EXISTS (
      SELECT 1
      FROM public.admin_users
      WHERE user_id = auth.uid()
        AND is_active = true
    );
$$ LANGUAGE sql STABLE SECURITY DEFINER;
```

Функция проверяет:
1. `auth.jwt()` - текущий JWT токен
2. `auth.uid()` - ID пользователя из токена
3. Наличие записи в `admin_users`

Если токен создан до добавления в admin_users - проверка пройдет только после новой сессии.

### Почему Service Role работает?

Service Role обходит RLS полностью и имеет полный доступ ко всем таблицам. Это используется только в server-side скриптах, никогда в браузере.
