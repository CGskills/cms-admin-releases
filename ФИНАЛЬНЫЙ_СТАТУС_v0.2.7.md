## 📊 Техническая информация

### Почему нужен перезапуск?

**Проблема:** JWT токен создан ДО добавления в admin_users  
**Следствие:** Функция is_admin() возвращает false  
**Решение:** Новая сессия = новый токен = is_admin() возвращает true

### Что проверяет is_admin()?

```sql
SELECT
  -- Проверка app_metadata
  (auth.jwt() -> 'app_metadata' ->> 'role') = 'admin'
  OR
  -- Проверка admin_users (наш случай)
  EXISTS (
    SELECT 1 FROM public.admin_users
    WHERE user_id = auth.uid() AND is_active = true
  );
```

Когда пользователь входит заново:
1. Создается новая сессия
2. auth.uid() возвращает правильный ID
3. Запрос находит запись в admin_users
4. is_admin() возвращает true ✅
5. RLS политика разрешает доступ ✅

**Таблица admin_users:**
