## ⚠️ ИЗВЕСТНЫЕ ПРОБЛЕМЫ

### 1. React Error #418 (не критичная)
```
Uncaught Error: Minified React error #418
```

**Статус:** Предупреждение, не блокирует работу  
**Влияние:** Нет (приложение работает)  
**Решение:** Можно игнорировать или подавить suppressHydrationWarning

### 2. Возможная ошибка startTime
```
Cannot read properties of undefined (reading 'startTime')
```

**Если появится:** Закройте окно code-library  
**Источник:** `/admin/code-library`  
**Решение:** Не переходить в code-library (это не основной функционал)

**Решение 1:** Проверьте вход
```

2. Email есть в .env.local ADMIN_EMAILS?
3. Проверьте статус входа в правом верхнем углу
```

**Решение 2:** Откройте DevTools (F12)
```
1. Нажмите F12 в приложении
2. Перейдите на вкладку Console
3. Проверьте, есть ли ошибки (красные строки)
4. Перейдите на вкладку Network
5. Проверьте запросы к Supabase (должны быть 200 OK)
```

**Решение 3:** Очистите кэш и пересоберите
```bash
rm -rf .next
npm run build
npm run desktop:prepare
npm run desktop:dev
```
