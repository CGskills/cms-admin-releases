## Ошибка: "Could not find the 'problem' column"

### Причина:
SQL миграция не была выполнена. Поля `problem`, `solution`, `result` отсутствуют в таблице `portfolio_items`.

### Шаг 2: Откройте SQL Editor

3. Нажмите **New query**

### Шаг 3: Скопируйте и выполните SQL

Скопируйте **ВЕСЬ** код из файла `URGENT_FIX.sql` или используйте код ниже:

```sql
-- URGENT FIX: Add missing columns
DO $$ 
BEGIN
    -- Add problem column
    IF NOT EXISTS (
        SELECT 1 FROM information_schema.columns 
        WHERE table_name = 'portfolio_items' AND column_name = 'problem'
    ) THEN
        ALTER TABLE portfolio_items ADD COLUMN problem TEXT DEFAULT '';
    END IF;

    -- Add solution column
    IF NOT EXISTS (
        SELECT 1 FROM information_schema.columns 
        WHERE table_name = 'portfolio_items' AND column_name = 'solution'
    ) THEN
        ALTER TABLE portfolio_items ADD COLUMN solution TEXT DEFAULT '';
    END IF;

    -- Add result column
    IF NOT EXISTS (
        SELECT 1 FROM information_schema.columns 
        WHERE table_name = 'portfolio_items' AND column_name = 'result'
    ) THEN
        ALTER TABLE portfolio_items ADD COLUMN result TEXT DEFAULT '';
    END IF;
END $$;

-- Remove UNIQUE constraint from slug
DO $$ 
BEGIN
    IF EXISTS (
        SELECT 1 FROM pg_constraint 
        WHERE conname = 'portfolio_items_slug_key'
    ) THEN
        ALTER TABLE portfolio_items DROP CONSTRAINT portfolio_items_slug_key;
    END IF;
END $$;

-- Create index on slug
CREATE INDEX IF NOT EXISTS idx_portfolio_items_slug ON portfolio_items(slug);
```

### Шаг 4: Нажмите "Run"

1. Нажмите кнопку **"Run"** или **Ctrl+Enter**
2. Подождите 2-3 секунды
3. Вы должны увидеть сообщение **"Success. No rows returned"**

### Шаг 5: Проверьте результат

Выполните проверочный запрос:

```sql
SELECT column_name, data_type 
FROM information_schema.columns
WHERE table_name = 'portfolio_items'
  AND column_name IN ('problem', 'solution', 'result')
ORDER BY column_name;
```

**Ожидаемый результат:**
```
column_name | data_type
------------|----------
problem     | text
result      | text
solution    | text
```

✅ Если вы видите 3 строки - **ОТЛИЧНО! Миграция выполнена!**
