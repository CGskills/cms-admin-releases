```

```

**Технические детали**:
- URL: `https://github.com/CGskills/cms-admin/releases/download/v0.2.3/latest.yml`
- Статус: 404 Not Found (без аутентификации)
- Статус: 404 Not Found (даже с токеном через curl)
- Причина: `electron-updater` не может получить доступ к приватным релизам
