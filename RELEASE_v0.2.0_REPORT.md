# 🎉 Release v0.2.0: Исправление выравнивания карточек сотрудников

## ✅ Что исправлено

### Проблема
В карточках сотрудников текст под статистикой был выровнен по нижнему краю, что создавало неровный вид.

### Решение
- Изменено выравнивание: `align-items: end` → `align-items: start`
- Удалены `flex` свойства из `.stat-label`
- Теперь весь текст выравнивается по верхнему краю (ровно)

### Изменённые файлы
- `components/employees/EmployeesSection.tsx`

## 📊 Что изменилось в коде

### Desktop версия (строки 350-396):

```css
/* ДО */
.card-stats {
  grid-template-columns: repeat(3, 1fr);
  gap: 40px;
  align-items: end;  /* ← выравнивание по низу */
}

.stat-label {
  font-size: 12px;
  min-height: 51px;
  display: flex;
  align-items: flex-end;  /* ← прижимало к низу */
}

/* ПОСЛЕ */
.card-stats {
  grid-template-columns: repeat(3, 1fr);
  gap: 40px;
  align-items: start;  /* ← выравнивание по верху */
}

.stat-label {
  font-size: 12px;
  min-height: 51px;
  /* flex удалён */
}
```
