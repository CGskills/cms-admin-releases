### 3. Функция is_admin() работает
```sql
CREATE OR REPLACE FUNCTION public.is_admin()
RETURNS boolean AS $$
  SELECT
    COALESCE((auth.jwt() -> 'app_metadata' ->> 'role') = 'admin', false)
    OR EXISTS (
      SELECT 1
      FROM public.admin_users
      WHERE user_id = auth.uid()
        AND is_active = true
    );
$$ LANGUAGE sql STABLE SECURITY DEFINER;
```

✅ Функция корректна  
✅ Проверяет таблицу admin_users при каждом запросе  
✅ Service role тесты подтверждают: данные читаются

## 🔴 ПРОБЛЕМА: Старая сессия без admin прав

### Почему возникла проблема?

1. **Пользователь вошел в приложение** → создалась сессия
2. **JWT токен создан** с `auth.uid() = 92a7525c-01e3-45f2-bc7d-4a0fedc3789f`
3. **Затем мы добавили** этого пользователя в `admin_users`
4. **Но JWT токен не обновляется** автоматически
5. **При запросе к code_blocks:**
   - RLS политика вызывает `is_admin()`
   - `is_admin()` проверяет `auth.uid()` в таблице admin_users
   - Находит запись и возвращает `true`
   - **НО** если токен очень старый или есть кеш, может быть проблема

### Техническое объяснение

```
TIMELINE:
─────────────────────────────────────────────────

09:00  Пользователь входит в приложение
       └─ Создается JWT токен
       └─ auth.uid() = 92a7525c...
       └─ admin_users: ПУСТО

09:30  Мы добавляем пользователя в admin_users
       └─ user_id: 92a7525c...
       └─ is_active: true

09:31  Пользователь открывает Code Library
       └─ Запрос использует СТАРЫЙ токен
       └─ is_admin() проверяет базу
       └─ Находит пользователя ✅
       └─ Но может быть проблема с кешем Electron
```

→ Старая сессия, перезапустить приложение

→ Проблема с .env.local, проверить NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

→ Таблица не создана, запустить миграции

**"Network error"**
→ Проблема с интернетом или Supabase недоступен

## 📦 ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ

### Database Schema

**code_blocks table:**
```sql
id UUID PRIMARY KEY
name TEXT NOT NULL
description TEXT
category TEXT
html TEXT          -- Полный HTML документ
css TEXT           -- Пустой (всё в html)
javascript TEXT    -- Пустой (всё в html)
version TEXT
status TEXT
dependencies JSONB
created_at TIMESTAMPTZ
updated_at TIMESTAMPTZ
```

**admin_users table:**
```sql
user_id UUID PRIMARY KEY REFERENCES auth.users(id)
is_active BOOLEAN NOT NULL DEFAULT true
created_at TIMESTAMPTZ
```

### RLS Policy

```sql
CREATE POLICY "CMS administrators full access"
  ON public.code_blocks FOR ALL TO authenticated
  USING (public.is_admin())
  WITH CHECK (public.is_admin());
```
