## ⚠️ ПРОБЛЕМА: Файлы заблокированы

Electron-builder не может пересобрать из-за блокировки файлов в `release/win-unpacked/`.

**Возможные причины:**
1. 🔴 CMS Admin Panel.exe запущен
2. 🔴 Антивирус сканирует/блокирует файлы
3. 🔴 Windows Explorer держит папку открытой

## ❓ Если появится новая ошибка "Cannot find module"

1. Найдите имя модуля в ошибке
2. Добавьте в `package.json` → `build.files`:
   ```json
   "node_modules/ИМЯ_МОДУЛЯ/**/*"
   ```
3. Пересоберите

## 💡 Альтернативный подход (если ошибки продолжаются)

Вместо whitelist используйте blacklist в `package.json`:

```json
"files": [
  "desktop/**/*",
  ".next/standalone/**/*",
  "node_modules/**/*",
  "!node_modules/@codemirror/**/*",
  "!node_modules/@dnd-kit/**/*",
  "!node_modules/@lezer/**/*",
  "!node_modules/@supabase/**/*",
  "!node_modules/@uiw/**/*",
  "!node_modules/next/**/*",
  "!node_modules/react/**/*",
  "!node_modules/react-dom/**/*"
],
```

⚠️ Увеличит размер приложения на ~20-50 МБ, но гарантирует включение всех dependencies.
