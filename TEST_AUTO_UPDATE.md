# Инструкция по тестированию автообновления

## 🎯 Цель теста
Проверить работу автоматического обновления с версии 0.2.1 на версию 0.2.2

## 📋 Что было исправлено

### Проблема
- Уведомление об обновлении приходило
- Кнопка "Скачать" не работала - обновление не загружалось

### Решение
1. **Улучшено логирование** - добавлены детальные логи на каждом этапе
2. **Исправлена обработка ошибок** - теперь при ошибке можно повторить попытку
3. **Включен production logging** - для диагностики проблем

## 🧪 Шаги тестирования

### 1. Подготовка
- Убедитесь, что у вас установлена версия 0.2.1
- Закройте все экземпляры приложения

### 2. Запуск приложения
```bash
# Запустите CMS Admin Panel из:
D:\admin\CMS Admin Panel\CMS Admin Panel.exe
```

### 3. Проверка текущей версии
- Откройте приложение
- В правом верхнем углу найдите иконку обновления (круговая стрелка)
- Наведите курсор - должна появиться подсказка "Проверить обновления"

### 4. Проверка обновлений
- Нажмите на иконку обновления
- Должно появиться сообщение "Проверка обновлений..."
- Через несколько секунд появится: "Доступна новая версия 0.2.2"

### 5. Загрузка обновления
- Нажмите кнопку **"Скачать"**
- Должен появиться прогресс-бар загрузки
- Отображается процент загрузки (0% → 100%)
- Показывается размер файла и скорость загрузки

### 6. Установка обновления
- После завершения загрузки появится кнопка **"Установить и перезапустить"**
- Нажмите на неё
- Приложение закроется и автоматически установит обновление
- Приложение перезапустится с новой версией 0.2.2

### 7. Проверка версии после обновления
- После перезапуска нажмите на иконку обновления
- Должно появиться: "Обновлений нет. Версия 0.2.2 актуальна"

## 🔍 Диагностика проблем

### Где смотреть логи

#### 1. Логи Electron (главный процесс)
```bash
# Windows
%APPDATA%\CMS Admin Panel\logs\main.log

# Или в консоли разработчика
# Откройте приложение и нажмите Ctrl+Shift+I (если DevTools включены)
```

#### 2. Логи браузерной консоли (UI)
- Если в приложении включены DevTools: `Ctrl+Shift+I`
- Вкладка "Console"
- Ищите сообщения с префиксом `[UpdateChecker]` и `[Main]`

### Типичные сообщения при успешной загрузке

```
[UpdateChecker] handleDownloadUpdate called { isElectron: true, status: 'available' }
[UpdateChecker] Starting download...
[UpdateChecker] Calling api.downloadUpdate()...
[Main] Starting update download...
[Main] Download initiated successfully
[UpdateChecker] Download initiated successfully
update-downloading { percent: 15.2, transferred: 26419200, total: 173804544, bytesPerSecond: 2621440 }
update-downloading { percent: 45.8, transferred: 79560704, total: 173804544, bytesPerSecond: 2621440 }
update-downloading { percent: 100, transferred: 173804544, total: 173804544, bytesPerSecond: 2621440 }
update-downloaded { version: '0.2.2' }
```

### Если загрузка не работает

#### Проверьте интернет-соединение
```bash
# Проверьте доступ к GitHub
ping github.com

# Проверьте доступ к релизам
curl -I https://github.com/CGskills/cms-admin/releases/tag/v0.2.2
```

#### Проверьте файл latest.yml
- URL: https://github.com/CGskills/cms-admin/releases/latest/download/latest.yml
- Должен содержать информацию о версии 0.2.2

#### Типичные ошибки

1. **"Updates are only available in production builds"**
   - Вы запускаете dev-версию
   - Используйте установленную версию из D:\admin

2. **"net::ERR_INTERNET_DISCONNECTED"**
   - Нет интернет-соединения
   - Проверьте сеть

3. **"ENOENT: no such file or directory"**
   - Проблема с временной папкой загрузки
   - Проверьте права доступа к %TEMP%

4. **"Cannot download update"**
   - GitHub может быть недоступен
   - Попробуйте позже

## 📊 Ожидаемые результаты

### ✅ Успешный тест
- Уведомление об обновлении появляется
- Кнопка "Скачать" запускает загрузку
- Прогресс-бар показывает процесс загрузки
- После загрузки можно установить обновление
- Приложение обновляется до версии 0.2.2

### ❌ Неудачный тест
- Кнопка "Скачать" не реагирует
- Прогресс-бар не появляется
- Появляется сообщение об ошибке
- Загрузка зависает на одном проценте

## 🐛 Если проблема сохраняется

1. **Откройте консоль разработчика**
   ```bash
   # Запустите с включенными DevTools
   set ENABLE_DEVTOOLS=1
   "D:\admin\CMS Admin Panel\CMS Admin Panel.exe"
   ```

2. **Соберите логи**
   - Скопируйте все сообщения из консоли
   - Скопируйте содержимое %APPDATA%\CMS Admin Panel\logs\

3. **Отправьте отчет**
   - Опишите шаги, которые вы выполнили
   - Приложите логи
   - Укажите версию Windows

## 🔄 Возврат к предыдущей версии

Если обновление вызвало проблемы:

1. **Удалите текущую версию**
   - Панель управления → Программы и компоненты
   - Найдите "CMS Admin Panel"
   - Нажмите "Удалить"

2. **Установите v0.2.1**
   - Скачайте с GitHub: https://github.com/CGskills/cms-admin/releases/tag/v0.2.1
   - Запустите установщик CMS-Admin-0.2.1-win-x64.exe
