## ⚙️ ДОПОЛНИТЕЛЬНО: Применение миграций

**Статус:** Необязательно, но рекомендуется для лучшей производительности

### Как применить:

1. Откройте Supabase Dashboard:
   https://supabase.com/dashboard/project/pjujhrfkykxgzcexyyti/sql/new

2. Выполните SQL из файлов:
   - `supabase/migrations/20260830_sequences_for_order_index.sql`
   - `supabase/migrations/20260830_batch_update_function.sql`

### Что это даёт:
- Автогенерация `order_index` без SELECT MAX
- Ускорение batch операций при reorder
- Улучшенная производительность при создании записей

**Примечание:** Приложение работает и БЕЗ этих миграций. Они нужны только для оптимизации.
