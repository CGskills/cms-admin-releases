## ❌ ЧТО НЕ РАБОТАЕТ

### React Error #418 при запуске Electron

**Ошибка:**
```
Uncaught Error: Minified React error #418
args[]=text&args[]=
```

**Что это означает:**
- React Hydration Mismatch
- Server-rendered HTML не совпадает с client-side ожиданиями
- React пытается гидратировать текстовый узел, но находит что-то другое

**Последствия:**
- ❌ Electron приложение падает сразу после запуска
- ❌ UI не загружается
- ❌ Приложение закрывается с кодом 0
- ❌ Пользователь видит пустое окно, которое сразу закрывается

**Где возникает:**
- На ЛЮБОЙ странице (включая client-only)
- При первой загрузке
- До инициализации React
- В корневом layout (app/layout.tsx)

## 💡 ВОЗМОЖНЫЕ ПРИЧИНЫ

1. **Next.js 16.3.1 + Turbopack баг**
   - Next.js 16 недавно вышел
   - Turbopack в production может иметь проблемы с Electron
   - Известно о проблемах hydration в новых версиях

2. **Electron модифицирует DOM**
   - Electron может инжектировать скрипты/стили в `<html>`
   - Preload скрипт может изменять структуру
   - CSP headers могут влиять на рендеринг

3. **Next.js standalone + Electron конфликт**
   - Standalone server может иметь особенности
   - Production mode ведет себя иначе чем dev
   - Статическая генерация страниц конфликтует с гидратацией

---

## 🛠️ ПРЕДЛАГАЕМЫЕ РЕШЕНИЯ

### ⭐ Решение 1: Откат на Next.js 15 (РЕКОМЕНДУЕТСЯ)

Next.js 15 стабильная версия без известных проблем с Electron.

```bash
npm install next@15 react@^18 react-dom@^18
npm run build
npm run desktop:dev
```

**Вероятность успеха:** 80%  
**Время реализации:** 10 минут

---

### ⭐ Решение 2: Отключить Turbopack

Turbopack - новая экспериментальная функция, может вызывать проблемы.

```json
// package.json
"build": "TURBOPACK=0 next build"
```

**Вероятность успеха:** 60%  
**Время реализации:** 5 минут

---

### Решение 3: Запускать Next.js в dev режиме

Вместо production build использовать `next dev` в Electron.

```js
// desktop/main.cjs
const nextServerProcess = spawn('npm', ['run', 'dev'], {
  cwd: serverRoot,
  env: childEnvironment,
});
```

**Вероятность успеха:** 90%  
**Время реализации:** 20 минут  
**Минусы:** Медленнее, больше памяти

---

### Решение 4: Полностью Client-Side приложение

Отключить SSR и сделать полностью SPA.

```tsx
// app/ClientApp.tsx
'use client';
export default function ClientApp() {
  return <div>...</div>;
}

// app/layout.tsx
export default function RootLayout({ children }) {
  return (
    <html suppressHydrationWarning>
      <body suppressHydrationWarning>
        <ClientApp />
      </body>
    </html>
  );
}
```

**Вероятность успеха:** 95%  
**Время реализации:** 1-2 часа  
**Минусы:** Теряем Server Components, Server Actions нужно переделать на API routes

---

Переписать приложение на Vite.

**Вероятность успеха:** 100%
